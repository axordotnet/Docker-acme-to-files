# v0.2.1

- Add daily dependency/digest update checks, including weekends, with protected PR review.
- Pin the Python multi-platform base digest while allowing Dependabot to propose replacements.
- Rebuild rolling images daily without cache and install available Debian package fixes.
- Add Trivy reports and block fixable HIGH/CRITICAL OS/library vulnerabilities.
- Scan both candidate architectures by exact digest before promoting latest/version tags.
- Add a release-tag ruleset ready for owner import and a GitHub security-settings checklist.
- Switch the standalone Vault Compose example to `latest` for rolling security updates.

Versioned deployments remain fixed. To receive security rebuilds, pull and recreate a container
using `latest`, or explicitly move to a newly published digest/version. Python interpreter updates
still require merging the base-digest PR. Reports may include vulnerabilities without available fixes.

The ruleset file is not automatically applied: repository administration access is required.
