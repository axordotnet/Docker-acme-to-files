# v0.2.0

- Add `PFX_PASSWORD` for Vault-injected environment secrets. When present, it overrides
  `PFX_PASSWORD_FILE` and `--password-file`; invalid or empty values fail without fallback.
- Preserve environment password bytes through UTF-8 encoding, including whitespace and
  trailing newlines. Existing file-secret behavior is unchanged.
- Provide a standalone `compose.vault.yaml` example. Recreate the container after an
  environment secret rotation; file-secret rotation remains detected through polling.
- Add password validation, precedence, Unicode, boundary and actual container tests.
- Integrate reviewed Dependabot dependency and GitHub Actions updates.
- Publish versioned AMD64/ARM64 images with SBOM, provenance and anonymous pull checks.

File-based deployments remain compatible. No migration is required unless switching to
environment injection. The environment is visible to operators with Docker inspection access;
the application never prints the password.
